# Redis分片集群

基于 Docker 的 Redis 分片集群部署脚本，支持自定义分片数和副本数。

## 功能特点

- 支持自定义分片数量和每个分片的副本数
- 自动配置和部署 Redis 集群
- 基于 Docker 容器，易于部署和管理
- 自动检测端口占用和系统兼容性
- 支持自定义 Redis 版本和密码
- 提供完整的连接信息和示例代码

## 使用方法

### 1. 基本用法

```bash
./init.sh
```

这将使用默认配置创建一个 Redis 集群：
- 3个分片（主节点）
- 每个分片1个副本
- 基础端口 6379
- Redis 版本 7.2
- 默认密码 123456

### 2. 自定义配置

```bash
./init.sh [选项]
```

可用选项：
- `-h, --help`                显示帮助信息
- `-n, --name NAME`           设置集群名称 (默认: redis-cluster1)
- `-p, --port PORT`           设置基础端口号 (默认: 6379)
- `-v, --version VERSION`     设置Redis版本 (默认: 7.2)
- `-w, --password PASSWORD`   设置Redis密码 (默认: 123456)
- `-s, --shards SHARDS`      设置分片数量 (默认: 3)
- `-r, --replicas REPLICAS`  设置每个分片的副本数 (默认: 1)
- `--host-ip IP`             手动指定主机IP (可选)

### 3. 示例

创建一个有4个分片、每个分片2个副本的集群：
```bash
./init.sh -s 4 -r 2
```

使用自定义端口和密码：
```bash
./init.sh -p 7000 -w mypassword
```

## 端口说明

- 每个节点需要两个端口：
  - Redis服务端口：从基础端口开始递增
  - 集群总线端口：服务端口 + 10000

例如，默认配置下的端口分配：
- 主节点：6379, 6380, 6381 (总线端口：16379, 16380, 16381)
- 副本节点：6382, 6383, 6384 (总线端口：16382, 16383, 16384)

## 目录结构

部署完成后会创建如下目录结构：
```
redis-cluster1/
├── compose.yaml           # Docker Compose 配置文件
├── README.md             # 集群信息和连接说明
├── redis-node-0/         # 主节点0数据目录
├── redis-node-1/         # 主节点1数据目录
├── redis-node-2/         # 主节点2数据目录
├── redis-replica-0-0/    # 主节点0的副本数据目录
├── redis-replica-1-0/    # 主节点1的副本数据目录
└── redis-replica-2-0/    # 主节点2的副本数据目录
```

## 注意事项

1. 确保系统已安装 Docker 和 Docker Compose
2. 所需端口未被占用
3. 主机防火墙允许集群端口访问
4. 建议在生产环境中修改默认密码
5. 集群创建后会自动生成连接信息到 README.md 文件

## 故障排除

1. 如果端口被占用：
   - 使用 `-p` 参数指定其他可用端口
   - 或先停止占用端口的服务

2. 如果无法获取主机IP：
   - 使用 `--host-ip` 参数手动指定IP

3. 如果容器启动失败：
   - 检查 Docker 服务状态
   - 查看容器日志：`docker logs 容器ID`

4. 如果集群创建失败：
   - 确保所有容器都在运行
   - 检查网络连接是否正常
   - 查看 Redis 日志是否有错误信息
