# Docker Compose 滚动更新脚本

一个通用的基于 Docker Compose 的容器滚动更新方案，支持零停机更新任何配置了健康检查的 Docker 服务。

## 核心功能

1. **零停机滚动更新**
   - 自动拉取最新镜像
   - 逐个替换现有容器，确保服务持续可用
   - 基于 docker compose scale 实现容器动态伸缩
   - 自动维持服务实例数量

2. **健康状态保障**
   - 自动检查新容器健康状态
   - 健康检查失败自动回滚
   - 确保服务可用性

3. **简单易用**
   - 无需特殊配置，开箱即用
   - 支持任何带健康检查的服务
   - 详细的状态日志输出

## 使用方法

### 1. 前置条件

- Docker 和 Docker Compose 环境
- 目标服务已在 docker-compose.yml 中定义
- 服务镜像已配置健康检查 (HEALTHCHECK)

### 2. 执行更新

```bash
./rolling-update.sh <服务名称>
```

更新流程：
1. 获取服务当前运行的容器数量
2. 拉取服务的最新镜像
3. 逐个替换容器：
   - 记录当前所有容器 ID
   - 增加一个新容器并强制使用新镜像
   - 识别新创建的容器
   - 等待新容器健康检查通过
   - 移除最旧的容器
   - 确保服务实例数量正确
4. 如遇异常自动回滚：
   - 移除未通过健康检查的新容器
   - 保持原有容器继续运行
   - 恢复原始实例数量

## 示例环境

为了演示和测试滚动更新效果，项目包含了一个简单的测试环境：

1. **示例 Web 服务**
   - 返回版本号的 HTTP 服务
   - 内置健康检查接口
   - 支持优雅关闭

2. **示例环境使用方法**
   ```bash
   # 构建示例服务
   ./build-example.sh
   
   # 启动测试环境
   docker compose up -d
   
   # 执行滚动更新测试
   ./rolling-update.sh web-example
   ```

## 最佳实践

1. **健康检查配置**

   - 避免过重的健康检查逻辑

2. **更新策略**
   - 确保服务支持多实例并行
   - 正确配置服务依赖关系
   - 合理设置更新超时时间

1. **镜像管理**
   - 确保镜像仓库有最新版本
   - 正确设置镜像标签
   - 保持镜像构建的一致性
